## The ACR Standard

I created the **ACR Standard**, an open-source specification for runtime control of agentic AI. It defines an architecture in which protected AI actions pass through a control plane that evaluates identity, purpose, policy, risk, and human authority before execution.

The standard is organized around six pillars:

1. Identity and purpose binding
2. Behavioral policy enforcement
3. Autonomy drift detection
4. Execution observability
5. Self-healing and containment
6. Human authority
